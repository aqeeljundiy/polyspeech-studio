# Learnings

Feedback the studio has absorbed, newest first. Claude reads this before every revision.

- 2026-10-20 · Pacing must sit in the middle: 60s with long holds felt slow, 18s felt rushed. Speed 1.3 on a calm timeline works.
- 2026-10-20 · Any small pill or badge must be perfectly centred, with its icon sized to the text and even padding.
- 2026-10-20 · Use real brand assets from the internet (official store badges) instead of drawing logos.
- 2026-10-20 · Dark overlays behind pop-ups read as "greyscale". Keep them light.
- 2026-10-20 · Captions must never change before they can be read. One idea per beat.
- 2026-10-20 · Show the real app: build screens from the code on main, never invented UI.
